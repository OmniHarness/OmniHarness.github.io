# OmniHarness Project Page

This repository contains the official project page for **OmniHarness: A Symbolic Cognitive Runtime for Self-Evolving Visual Agents**.

The site is a static page. Its main entry point is `index.html`, with project-specific styles, interactions, figures, benchmark results, images, and videos stored under `static/`.

## Local preview

Serve the repository root with any static HTTP server and open `index.html` through the local server URL.

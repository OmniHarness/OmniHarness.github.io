O m n i H a r n e s s : A Symbolic Cognitive Runtime for Self-Evolving Visual Agents

arXiv Code

Abstract

Visual generation agents have rapidly advanced with unified multimodal large language models (MLLMs) and multi-agent systems. Inspired by Kahneman’s dual-process theory, we argue that self-evolving visual intelligence requires moving beyond fast generation and deliberative reasoning toward a unified cognitive runtime that can organize, accumulate, and evolve intelligence over time. Existing MLLMs provide efficient generation but lack explicit reasoning, verification, and self-correction, while multi-agent systems improve collaboration but lack persistent mechanisms for capability evolution. Moreover, most agentic systems acquire new capabilities only in response to predefined tasks, making continual learning reactive rather than proactive. To address these limitations, we propose OmniHarness, a symbolic cognitive runtime for self-evolving visual agents. OmniHarness instantiates the harness paradigm by integrating reasoning, execution, memory, and feedback into a unified architecture that coordinates agent behaviors and transforms execution experiences into reusable knowledge. It further introduces curiosity-driven play, enabling agents to autonomously explore and practice novel but learnable tasks before downstream objectives are specified. Through symbolic knowledge evolution, OmniHarness converts acquired experiences into reusable capabilities without fine-tuning the underlying model. Extensive experiments demonstrate that OmniHarness improves complex visual generation tasks, supports continual capability expansion, and provides a plug-and-play mechanism for enhancing existing visual agent systems.
